# Support

Agents Kit is maintained by an individual on a best-effort basis.

## Where to ask

- **Bug reports:** open a GitHub issue using the bug report template and include a minimal,
  reproducible example with synthetic data.
- **Feature requests:** open an issue using the feature request template. Explain the
  problem first and keep the proposed change focused.
- **How-to questions:** open a GitHub issue with the module, version, Python version, and
  the smallest relevant code sample.
- **Security reports:** do not use public issues. Follow [SECURITY.md](SECURITY.md).

## What to include

- Agents Kit version.
- Python version and operating system.
- The exact public API being used.
- Expected behavior and actual behavior.
- A minimal reproduction that does not contain secrets or personal data.

## Scope

The project provides small Python building blocks, not hosted services or guaranteed
production support. Response times are best-effort; no service-level agreement is offered.
